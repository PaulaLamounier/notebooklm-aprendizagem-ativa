# 🤖 Tendências de IA Corporativa para 2026 e Visão Estratégica

## 🎯 Contexto do Projeto

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa e organização do conhecimento.

O tema escolhido foi:

> Tendências de IA Corporativa para 2026 e Estrutura de Visão Estratégica

O estudo teve como foco compreender como a Inteligência Artificial está impactando o ambiente corporativo, especialmente em áreas relacionadas à análise de negócios, transformação digital, agilidade organizacional e tomada de decisão estratégica.

As pesquisas e análises foram realizadas com apoio do NotebookLM, utilizando fontes relacionadas a:
- Inteligência Artificial Corporativa;
- Análise de Negócios;
- Lean Inception;
- Scrum;
- Estratégia Organizacional;
- Transformação Digital.

---

## 🚀 Objetivos de Aprendizagem

- Explorar o uso do NotebookLM como apoio à aprendizagem;
- Consolidar conhecimentos sobre IA corporativa;
- Identificar tendências estratégicas para 2026;
- Desenvolver habilidades de curadoria de conteúdo;
- Aplicar engenharia de prompts para extração de conhecimento;
- Construir um material de estudo reutilizável.

# 📖 Fontes Utilizadas
